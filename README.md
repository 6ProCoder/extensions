# Roblox Browser Extensions (PC)
Here I will upload browser extensions for **Roblox** (PC).

## 🧩 Available Extensions

### 1. Roblox Lite Site (English & Greek Versions)
A fast, lightweight Roblox dashboard with live game status, online friends, Continue history, Direct Join, Server Hop, and playtime reminders.
* **English Version** (`Roblock Lite Site` folder): For international users.
* **Greek Version** (`Roblox Lite Site` folder): Translated and tailored for Greek users (Ελληνική έκδοση).

## 🚀 How to Install
1. Download the folder of the extension version you want (or download the repository as a ZIP and extract it).
2. Open your browser (Chrome, Edge, Brave, etc.) and go to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the extension's folder.
