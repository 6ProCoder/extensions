# Browser Extensions (PC)
Here I will upload various browser extensions for PC.

## 📂 Categories (Branches)
The extensions are organized into separate **branches** by category so everything stays clean:
* **`Roblox`** – Extensions and tools for Roblox.
* *(More categories coming soon!)*

**How to switch categories:**
1. Click the **`main`** branch dropdown button at the top-left of the file list.
2. Select the category branch you want from the list.
3. Download the extension folder you need!

## 🚀 How to Install
1. Go to the category branch you want and download the extension folder (or click **<> Code** > **Download ZIP** and extract it).
2. Open your browser (Chrome, Edge, Brave, etc.) and go to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the extension's folder.
